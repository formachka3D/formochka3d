# Политика конфиденциальности Formochka3D Help

Дата обновления: 7 октября 2026 г.

Настоящая Политика конфиденциальности описывает обработку данных сервисом **Formochka3D Help**, используемым для управления профессиональным Instagram-аккаунтом Formochka3D, публикации контента, обработки комментариев и входящих сообщений.

## 1. Какие данные обрабатываются

При подключении Instagram через официальный Meta / Instagram API сервис может получать и обрабатывать только данные, доступ к которым пользователь явно разрешил при авторизации, в том числе:

- идентификатор и имя пользователя профессионального Instagram-аккаунта;
- данные о публикациях и медиа, необходимые для размещения и управления контентом;
- комментарии к публикациям и связанные с ними идентификаторы;
- входящие сообщения Direct и идентификаторы отправителей, когда это необходимо для ответа;
- технические токены доступа Instagram API;
- технические журналы запросов и событий, необходимые для диагностики и безопасной работы сервиса.

Formochka3D Help не запрашивает пароль Instagram и не хранит его.

## 2. Для чего используются данные

Данные используются для:

- публикации подготовленного контента в Instagram;
- отображения статуса и истории публикаций в Help;
- получения и обработки комментариев;
- обработки входящих сообщений Direct;
- выполнения заранее настроенных пользователем правил автоматизации;
- диагностики ошибок, защиты сервиса и предотвращения злоупотреблений.

Автоматические ответы включаются пользователем отдельно. Сервис не должен отправлять сообщения вне разрешённых Meta сценариев взаимодействия.

## 3. Хранение и безопасность

Данные хранятся только в объёме, необходимом для работы сервиса и выполнения указанных выше целей. Доступ к административной части Help ограничен. Токены доступа не публикуются и используются только для обращения к официальным API Meta / Instagram.

Данные и технические записи удаляются, когда они больше не нужны для указанных целей, если более длительное хранение не требуется законом или для разрешения технических либо договорных вопросов.

## 4. Передача третьим лицам

Данные не продаются рекламодателям или иным третьим лицам. Передача может происходить только поставщикам инфраструктуры и сервисов, необходимым для работы Formochka3D Help, либо в случаях, предусмотренных законом.

При работе с Instagram данные также обрабатываются Meta Platforms в соответствии с её собственными условиями и политиками.

## 5. Удаление данных и отзыв доступа

Пользователь может в любой момент:

- отключить Instagram от Formochka3D Help;
- отозвать разрешения приложения в настройках Instagram / Meta;
- запросить удаление сохранённых данных, написав на **support@formochka3d.ru**.

После получения подтверждённого запроса данные, которые не требуется хранить по закону, удаляются или обезличиваются.

## 6. Права пользователя

Пользователь может запросить сведения об обработке данных, их уточнение, ограничение обработки или удаление в случаях, предусмотренных применимым законодательством.

## 8. Изменения политики

Политика может обновляться при изменении функций Formochka3D Help, требований Meta / Instagram API или применимого законодательства. Актуальная версия публикуется по этому адресу.
